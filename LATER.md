# Later

Ideas that are not the one job (folder → character → pose → transparent PNG). One line each. None of these is built until version 1 is public and the owner picks one.

- More of a place: building water, the game's sky, weather and time of day, cast shadows, moving props, people and animals, a camera that walks (standing in the world is built)
- The 3D character-select screens as places
- Spots saved by the addon listed on the page (a pasted line from /mogshot spot is built)
- Animation sequences
- Stickers, and a choice of fonts and colours for the title (a title and a second line are built)
- Share codes
- 3D export
- Creatures on the page, and mounts (NPCs and creatures by display id or name are built on the command line; a creature model's variant sections are all shown, since which the game shows is not read)
- Import from the armory (the addon import is built)
- User accounts
- Safari and Firefox support
- Particle and ribbon effects on items
- A legs-slot skirt (an NPC's long dress) should hide boot tops as a robe does; only a chest item's skirt does now
- Guild tabard emblems
- Reading models whose skeleton is in a separate `.skel` file (retail's newer races)
- Decrypting data whose keys are public (other WoW products)
- Remembering the folder for folders outside /Applications and Program Files, where Chrome's picker is allowed
